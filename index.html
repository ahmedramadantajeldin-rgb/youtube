ℹ Platform Boundary
In-Page Feed & Search Shelves on youtube.com: Because this PWA navigates to the official YouTube website (cross-origin), web platform security (Same-Origin Policy) strictly prevents external web apps from altering YouTube's internal DOM elements, recommendations, or search result shelves once you are browsing on youtube.com.

Device Guidance: Android

Limitation: Google Chrome on Android blocks browser extensions from running, so an installed Chrome PWA cannot inject cosmetic filters into youtube.com.

Solution: To get complete in-page Shorts removal on Android, use Firefox for Android or Kiwi Browser with the uBlock Origin extension installed, then import the filter rules below.

Device Guidance: iOS / iPadOS

Limitation: Apple's Safari Web Clips (Home Screen PWAs) run in a sandboxed WebKit process that disables Safari Web Extensions.

Solution: Use Safari directly with a content blocker (e.g. AdGuard or Unhook), or use the Subscriptions launch feed above to bypass Home Shorts.

Device Guidance: Desktop (Chrome / Edge / Firefox)

Supported: Content blocker extensions like uBlock Origin and Unhook run inside installed desktop PWAs! Adding the filter rules below works immediately inside your installed PWA window.
